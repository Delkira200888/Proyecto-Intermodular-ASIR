# 2. Arquitectura y Servicios

## 2.1. Descripción general de la arquitectura
Para dar soporte al salto al comercio electrónico de la ferretería tradicional, se diseñará una arquitectura basada en servicios centralizados que garanticen la disponibilidad, la seguridad transaccional y la facilidad de gestión para el propietario del negocio.

## 2.2. Componentes principales
- **Servidor Web / Frontend:** Encargado de alojar la interfaz de usuario de la tienda online (catálogo de productos, carrito de compra y pasarela de atención).
- **Servidor de Base de Datos:** Sistema gestor de bases de datos relacionales para almacenar de forma segura el catálogo de productos, el stock disponible, los datos de los clientes y el registro de pedidos.
- **Sistema de Seguridad y Control Perimetral:** Mecanismos orientados a cifrar las comunicaciones (certificados SSL/TLS) y proteger el acceso frente a accesos no autorizados.
- **Sistema de Copias de Seguridad:** Automatización periódica de respaldos tanto de la base de datos como de los ficheros multimedia del catálogo.
